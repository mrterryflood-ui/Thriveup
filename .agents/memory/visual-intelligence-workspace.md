description: Shared GIS evidence shell and boundaries for place, data, comparison, resources, story, and impact views.
---

The visual-intelligence workspace uses `/community-analysis` as its primary entry point and composes existing map, SDOH, resource, comparison, brief, and impact routes through one evidence-aware shell. Legacy routes remain compatibility destinations, not competing primary navigation.

**Why:** Multiple existing GIS surfaces had different provenance, geography, vintage, and modeled-value language. A shared shell makes those distinctions visible without replacing the existing Leaflet/OSM and provider pipelines.

**How to apply:** Preserve source-reported geography grain, vintage, refresh status, and observed/derived/modeled/unavailable class at the claim level. Never present synthetic 3D or modeled values as observed outcomes; prefer source-backed maps, tables, and explicit unavailable states.
