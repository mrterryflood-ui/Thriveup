---
name: User Journey Spine
description: The product reason for carrying user context across tools rather than maintaining disconnected intake silos.
---

Preserve relevant user context across tools through the canonical journey rather than making people repeat their situation at each handoff.

**Why:** The shared-journey approach was chosen to address disconnected Navigator, screening, referral, and youth workflows. A common need must not be lost merely because the person changes tools.

**How to apply:** Inspect current capture hooks and readers before diagnosing a disconnected handoff. Earlier notes saying screening/referral capture was unwired became stale; do not use historical wiring notes as proof. Treat shared context as a workflow mechanism, not an authorization grant or proof that every handoff is complete.
