# RPLICE — The Research-to-Practice Implementation Platform

## Overview
RPLICE is an AI-assisted platform designed to bridge the research-to-practice gap in implementation science. Its core purpose is to translate evidence-based research into routine practice more effectively by integrating evidence discovery, implementation design, project execution, evaluation, and sustainment. The platform operationalizes established implementation frameworks (CFIR 2.0, RE-AIM, EPIS, FAST, MADI, ADKAR, IRLM) and utilizes the MAP-GAP methodology for adaptive learning. It supports diverse operational modes such as Implementation Science, Military Planning, and Climate & Environment, aiming to accelerate implementation speed as measured by the FAST framework. RPLICE incorporates a comprehensive AI knowledge base, including the 2026 Springer special collection on implementation science advancements, to drive its capabilities.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### UI/UX Decisions
The platform features a modern, responsive UI built with React 18, TypeScript, Tailwind CSS, and shadcn/ui, offering both light and dark modes. Key UX elements include a global command palette, persona-based quick starts, PWA support, an 8-section collapsible sidebar, lifecycle-aware tool recommendations, and a comprehensive Help & Manual. A "Guided Start" provides role-specific journeys, and an Educational Design System is used to scaffold AI output and user learning, emphasizing human expertise amplification.

### Technical Implementations
The frontend uses Vite, Wouter for routing, TanStack React Query for state management, and React Hook Form with Zod for forms. The backend is an Express.js application in TypeScript with PostgreSQL and Drizzle ORM. AI capabilities are integrated via OpenAI, Anthropic Claude, and Perplexity Sonar Pro. Authentication is session-based using magic links, and AI chat responses are rendered with ReactMarkdown. DALL-E 3 is used for image generation.

Core features include:
- **Unified Project Assessment Pipeline**: Automates project assessment for "Implementation" and "Research Protocol" modes, supporting multi-site capabilities and PPTX export.
- **Smart Plan Generator**: Provides multi-modal input, AI orchestration, an 8-step implementation wizard, comparison views, branching scenarios, and multi-format export.
- **User Workspace**: Offers per-user sandboxes, a personal AI assistant, document management, and project creation.
- **Evidence-Based Programs Gateway**: Aggregates 14 major evidence registries and streamlines project creation.
- **Unified Evidence Discovery System**: Searches 4 live scholarly databases and 13 evidence registries with AI-generated insights.
- **Custom Tool Builder**: Enables autonomous tool creation with automated quality checks.
- **Project Workflow**: A 6-step Project Wizard with AI recommendations, Validation & Fidelity Hub, and SALP engine for continuous improvement.
- **Action-Oriented Tools**: Supports the ASSESS → UNDERSTAND → APPLY → DISSEMINATE cycle.
- **Scale-Up & Spread Planner**: A comprehensive tool for scaling evidence-based interventions, including scaling factor assessments, the Hexagon Tool, and integration of multiple scaling frameworks.
- **Discipline Rosetta Stone**: A cross-discipline translation tool supporting 14 professional disciplines, featuring AI-powered content translation, a universal crosswalk table, and multiple output formats.
- **9 Advanced IS Gap-Filling Tools**: Includes Re-Implementation Workflow, Implementation Climate Assessment, Dynamic Barriers & Facilitators, De-Implementation Planning, MADI Adaptation Tracker, Champion Preparation ADKAR, Implementation Costing, Equity-Focused TMF Adapter, and Context-Adapted ERIC Strategies.
- **CFDE Dataset Explorer**: Facilitates browsing and analysis of 17 NIH Common Fund datasets for research proposals, with live API access and AI-powered cross-dataset analysis.
- **Evidence-to-Impact Lifecycle Dashboard**: Manages a 7-stage lifecycle from evidence to community impact, featuring AI-generated implementation plans, role-specific views, HIPAA-compliant data access, and qualitative data capture.
- **Case Studies Showcase** (`/case-studies`): Three interactive Evidence-to-Impact lifecycle case studies: (1) MoTrPAC Exercise Biomarker Screening (San Antonio TX, health/biomedical), (2) Workplace Financial Wellness (Detroit MI, financial/workforce), and (3) Austin Hybrid Transit (Austin TX, urban policy/SDOH — FEATURED EXAMPLE). Each walks all 7 stages with downloadable PPTX + DOCX. Demonstrates platform versatility and scientific replicability across domains.
- **Austin Transit Feasibility Study** (`/transit-feasibility`): Full Evidence-to-Impact lifecycle-framed analysis of hybrid rideshare credits vs. low-ridership bus routes. Includes 7-stage lifecycle tracker, interactive ROI calculator, crime/education/health impact modeling, City Council motions, and "How This Was Built" explainer. Labeled as FEATURED EXAMPLE. Links to city-specific micro plans.
- **Transit City-Specific Micro Plans** (`/transit-city-plans`): Three city-specific micro transit implementation plans adapted from the macro transit concept. Same 3-city structure as exRNA: San Francisco (Muni/SFMTA, union negotiations, multilingual), Fayetteville NC (FAST transit, Ft. Liberty military, rural-adjacent), Austin TX (Capital Metro, East Austin equity, Council-ready). Each city has CFIR barriers, ERIC strategies, RE-AIM targets, PDSA cycles, fidelity plan (FIXED rideshare mechanism vs ADAPTABLE routes/credits/partners), data governance, and EPIS timeline. 8 downloadable documents via `scripts/generate-transit-docs.ts`.
- **exRNA + Metabolomics Implementation Plan** (`/exrna-implementation`): Macro-level implementation plan bridging two CFDE datasets (exRNA Atlas + Metabolomics Workbench) for non-invasive liquid biopsy screening at community health centers. Covers BLUF, evidence synthesis, target conditions, CFIR 2.0/RE-AIM/EPIS frameworks, site selection (San Francisco, Fayetteville NC, Austin TX), licensing/regulatory pathway, entity roles (ThriveUp/CAF/CIP), HIPAA tiers, R03 grant connection (RFA-RM-26-017), and cross-dataset analysis. Macro document before city-specific adaptation.
- **exRNA City-Specific Micro Plans** (`/exrna-city-plans`): Three city-specific micro implementation plans adapted from the macro plan. Each city has: city-specific BLUF, real Census demographics, healthcare infrastructure map, city-specific CFIR barrier scoring (9 constructs with different weights), adapted ERIC strategies, city-adapted RE-AIM targets, 3 PDSA cycles per city, fidelity monitoring (FIXED core panel vs ADAPTABLE workflow), local partnership map, adaptation boundaries with flexibility ratings, HIPAA implementation per city, and EPIS timeline. Cities: San Francisco (UCSF/FQHC/multilingual), Fayetteville NC (military/veteran/TBI-PTSD), Austin TX (Dell Med/East Austin equity/promotoras). 8 downloadable documents (1 macro + 3 city × PPTX + DOCX) generated via `scripts/generate-exrna-docs.ts`.
- **Resilience & Validation Infrastructure**: Enforces a "5-Point Resilience Pattern" including data persistence, type safety, validation, atomicity, and fault tolerance, with AI response validation using Zod schemas.

### System Design Choices
The data layer utilizes PostgreSQL with Drizzle ORM. Development uses `tsx`, with esbuild for server production builds and Vite for client builds. Security measures include session security, CSRF protection, rate limiting, security headers, audit logging, and input sanitization. Comprehensive SEO infrastructure is also in place.
