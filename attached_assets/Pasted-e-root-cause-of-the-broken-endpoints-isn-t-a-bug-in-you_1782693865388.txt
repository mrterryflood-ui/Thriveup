1. Fix the Production Routing (The Catch-All Swap)
The reason thrivingcommunitiesforall.com/api/community suddenly started returning SPA HTML instead of JSON is an Express/Vite router precedence conflict.

In your server configuration, the static asset catch-all middleware (*) was evaluated before or simultaneously with your API router. When a production build triggers, the server treats the API paths as client-side routes, swallowing the JSON payload and serving the index page instead.

The Prevention Code: Ensure your backend route mounting explicitly isolates and terminates the API router before the frontend engine can touch it:

TypeScript
// Move this block to the absolute top of your server middleware pipeline, 
// BEFORE any express.static or client-side routing catch-alls.
app.use('/api', apiRouter);

// Explicit 404 handler for missing API routes to prevent HTML leaking
app.use('/api/*', (req, res) => {
  res.status(404).json({ error: "API endpoint not found on this node." });
});

// Front-end SPA catch-all must ALWAYS live at the very bottom
app.get('*', (req, res) => {
  res.sendFile(path.resolve(__dirname, '../dist/index.html'));
});
