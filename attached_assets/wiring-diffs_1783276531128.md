# ThriveUp Academy — Learner Event Bus Wiring

## 1. Add the import to both route files

At the top of `server/trade-sims-routes.ts` and `server/workforce-routes.ts`, add:

```typescript
import { fireLearnerEvent } from "./learner-events";
```

---

## 2. server/trade-sims-routes.ts — around line 240–248

### BEFORE:
```typescript
const [inserted] = await db
  .insert(tradeSimsLessonProgress)
  .values({
    ...payload,
    userId: scope.userId ?? null,
    anonSessionId: scope.anonSessionId ?? null,
    attemptCount: 1,
  })
  .returning();
res.json(inserted);  // ← dead end
```

### AFTER:
```typescript
const [inserted] = await db
  .insert(tradeSimsLessonProgress)
  .values({
    ...payload,
    userId: scope.userId ?? null,
    anonSessionId: scope.anonSessionId ?? null,
    attemptCount: 1,
  })
  .returning();

// 🔥 Fire learner event — this is what connects the sim to XP, quests, certs
if (scope.userId && inserted.status === "completed") {
  await fireLearnerEvent(
    {
      type: "trade_lesson_completed",
      userId: scope.userId,
      userName: scope.userName ?? "Learner",
      metadata: {
        lessonId: payload.lessonId,
        tradeId: payload.tradeId,
        score: payload.score ?? null,
      },
    },
    db
  );
}

res.json(inserted);
```

> ⚠️ If `payload.tradeId` doesn't exist yet in your request body schema, add it
> to the Zod validator for this route and pass it from the frontend when a lesson
> completes. The trade sim lesson page already knows which trade it's in.

## 3. server/workforce-routes.ts — around line 359–360

### BEFORE:
```typescript
const [placement] = await db
  .insert(jobPlacements)
  .values(parsed.data)
  .returning();
res.json(placement);
```

### AFTER:
```typescript
const [placement] = await db
  .insert(jobPlacements)
  .values(parsed.data)
  .returning();

// 🔥 Fire learner event — placement now surfaces in WIOA dashboard + outcome tracking
await fireLearnerEvent(
  {
    type: "job_placement_recorded",
    userId: parsed.data.userId,
    userName: parsed.data.userName ?? "Learner",
    metadata: {
      employerName: parsed.data.employerName,
      wage: parsed.data.wage,
      startDate: parsed.data.startDate,
    },
  },
  db
);

res.json(placement);
```

## What fires after a completed trade lesson (the full chain):

```
learner completes lesson
  → tradeSimsLessonProgress INSERT
  → fireLearnerEvent("trade_lesson_completed")
      → +50 XP to student_progress (upsert)
      → outcome_tracking row: lesson_completed
      → check: all lessons in trade done?
          YES → fireLearnerEvent("trade_completed")
              → +200 XP
              → certificates INSERT
              → outcome_tracking: trade_certification_earned
              → check: 3+ certs?
                  YES → outcome_tracking: workforce_pell_eligible
```

Every step is wrapped in try/catch. Nothing in this chain can crash the
original `res.json(inserted)` response.
