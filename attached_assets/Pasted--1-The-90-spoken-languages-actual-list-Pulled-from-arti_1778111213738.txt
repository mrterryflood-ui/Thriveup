3. Crisis-detection escalation path — the honest version
This is what actually exists today, not what's planned:

Detection. GPT-5.2 runs in parallel with every translation request (POST /api/interpret/sessions/:id/speak in interpret.ts:626-633) using a dedicated CRISIS_DETECTION_PROMPT. Returns one of five levels: none / mild / moderate / severe / critical, plus indicators[] and recommendedAction. Pre-seeded crisis keywords per language (e.g. "救命", "ayuda", "no puedo respirar", "ਮਦਦ", and signed equivalents like "HELP", "CANT-BREATHE") boost recall on top of LLM analysis.
Persistence. Every detected crisis writes crisisLevel and crisisIndicators onto the message row, and flips crisisDetected=true on the parent session — which means measurable outcome data for grant reporting (queryable: number of sessions where crisis was detected, by language, by severity).
In-app escalation. severe and critical returns a crisisAlert payload that surfaces a banner with the indicators and a recommended action.
Human handoff — what's wired up:
Two large tap targets, always visible on /interpreter/crisis: tel:911 (red, "Call 911") and tel:988 (blue, "988 Crisis Line"). These open the device's native dialer — no API integration with 988 (their public API doesn't allow third-party dispatch), so the user places the call themselves.
No automated dispatch to 988 (it would be misleading to claim that — 988 doesn't expose a dispatch API).
No live human interpreter handoff yet — that's the natural next-grant-cycle line item.
No automatic LifeBridge/ecosystem-partner routing for crises yet. What is wired: the ThriveUp ecosystem connector exposes a crisis alerts can be routed to ecosystem partners integration point in its capability announcement, so partner platforms (LifeBridge included) can subscribe — but the routing logic itself is queued, not shipped.
Honest framing for the proposal: "Crisis detection runs on every utterance in 108 languages, classifies severity into 5 levels, persists structured outcome data to the database, and presents one-tap dialer access to 911 and 988. Grant funds will extend this with (a) automated warm-handoff to ecosystem-partner human interpreters via the ThriveUp pub/sub bus, and (b) opt-in 988 chat-API integration once available."
