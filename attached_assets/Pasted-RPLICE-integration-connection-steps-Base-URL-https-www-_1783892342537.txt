RPLICE integration — connection steps
Base URL: https://www.bettersciencelab.com
1. Get your API key
We’ll create one for you on https://www.bettersciencelab.com/api-docs (log in → “Create API key” → copy the key once; it won’t show again).
Store it as a secret. Format: rplice_<token>
2. Auth on every request
Authorization: Bearer rplice_<your_key>
Content-Type: application/json
Rate limit: 120 requests/minute per key.
3. Start here — endpoint index (no auth required)
GET https://www.bettersciencelab.com/api/v1/partner/data/catalog
That returns every partner endpoint. Use it as your integration map.
Secondary index for compute/stats engines:
GET https://www.bettersciencelab.com/api/v1/partner/execution/catalog
4. Smoke test
curl -H "Authorization: Bearer rplice_<your_key>" \
  https://www.bettersciencelab.com/api/v1/frameworks
You should get 53 frameworks back.
5. Main endpoints to wire up
Use case	Method	Path
Framework library	GET	/api/v1/frameworks
Single framework	GET	/api/v1/frameworks/:id
CFIR 2.0 taxonomy	GET	/api/v1/cfir/constructs
SALP canon	GET	/api/v1/salp/canon
Equity / needs / sustainability rubrics	GET	/api/v1/equity-evaluation/rubric, /api/v1/needs-assessment/schema, /api/v1/sustainability-wizard/rubric
Implementation strategies (ERIC)	GET	/api/v1/implementation-strategy/taxonomy
Match barriers → strategies	POST	/api/v1/implementation-strategy/match body: {"barriers":["staff turnover","funding"]}
Community indicators by FIPS	POST	/api/v1/community-analysis
Fidelity scoring	POST	/api/v1/fidelity/score
Grant funder profiles	GET	/api/v1/grants/profiles
Grant alignment	POST	/api/v1/grants/alignment body: {"projectDescription":"..."}
Research search	GET	/api/v1/research?q=implementation&framework=CFIR&limit=50
Federal data catalog metadata	GET	/api/v1/federal-integrations
6. Community analysis (FIPS) — primary data pull
POST https://www.bettersciencelab.com/api/v1/community-analysis
{
  "fips": "48453",
  "domains": ["poverty", "housing", "behavioral_health", "crime"]
}
Or: "stateFips": "48", "countyFips": "453".
Omit domains to get all 15 domains.
Alias path also works: POST /api/community-analysis (same body, same auth).

9. What you don’t need
No OAuth
No CSRF token on /api/v1/* or /api/research/*
Don’t use the old /api/v1/frameworks stub if you only see 6 frameworks — that means the new partner layer isn’t deployed yet
