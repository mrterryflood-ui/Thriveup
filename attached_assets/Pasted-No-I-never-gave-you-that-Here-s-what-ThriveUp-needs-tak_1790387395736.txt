**Message for ThriveUp: ChildCORE partner connection**

**1. ChildCORE → ThriveUp (outbound county-metrics push)**
- **Endpoint:** `POST https://easyailearning.com/api/childcore/county-metrics/ingest`
- **Auth headers:** `x-partner-key: <ChildCORE's ThriveUp key>` and `Authorization: Bearer <same key>`, with `Content-Type: application/json`
- **Payload (JSON):** `source` ("ChildCORE"), `dataType` ("metric"), `county_fips`, `county_name`, `state`, `as_of_date` (YYYY-MM-DD), `total_providers`, `total_licensed_capacity`, `estimated_demand`, `slot_gap`, `coverage_rate`. Each count also has a matching `_suppressed` true/false flag, plus `suppression_reason: "cell_below_floor_5"`. Any count under 5 is sent as null (the YHSI suppression floor).
- **Frequency:** a scheduled heartbeat check every 6 hours, plus a push when an organization's Impact page triggers one.

**2. ChildCORE also calls these ThriveUp APIs** (base `https://easyailearning.com/api/partner/v1`, same headers)
- `POST /heartbeat`, `GET /community-brief`, `GET /early-warnings`
- `POST /chainweb/scenarios`, `/chainweb/scenarios/{id}/calculate`, `GET /chainweb/coefficients`, `GET /chainweb/templates`
- `GET /yhsi/outcomes-summary`, `GET /yhsi/metrics`
- **What we need from ThriveUp:** turn on the **`chainweb:read`** and **`yhsi:read`** scopes for ChildCORE's key. Those calls currently return 403 or null.

**3. ThriveUp → ChildCORE (inbound API)**
- **Base URL:** `https://<ChildCORE Convex deployment>.convex.site/api/v1`
- **Auth:** `X-ChildCORE-Key: <key>` or `Authorization: Bearer <key>`. Default rate limit is 100 requests per hour.
- **Endpoints:**
  - `GET /ping` (no auth)
  - `GET /community/{ZIP or county FIPS}/providers`, `/schools`, `/impact`, `/sdoh`, `/coverage_gap`
  - `POST /push` (ThriveUp sends data to ChildCORE)
- **Scopes:** `read:providers`, `read:schools`, `read:impact`, `read:sdoh`, `read:coverage_gap`, `push:metrics`

**4. Webhooks: ThriveUp → ChildCORE**
- `POST https://<ChildCORE Convex deployment>.convex.site/webhooks/thrive`
- Events go in the `X-Thrive-Event` header: `grant.opportunity.new`, `referral.created`, `referral.outcome`
- Signature: a hex HMAC-SHA256 of the raw body in the `X-ThriveUp-Signature` header, using a shared secret we exchange privately.
