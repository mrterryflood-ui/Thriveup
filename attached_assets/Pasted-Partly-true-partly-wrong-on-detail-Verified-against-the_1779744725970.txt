Partly true, partly wrong on detail. Verified against the actual code:

True parts

Literature router is implementation-science scholarly lit, not federal-statistic primary sources. /api/literature wraps PubMed, NIH iCite, OpenAlex, Crossref, and Springer Nature (server/literature-routes.ts, server/literature-openalex-routes.ts, server/literature-crossref-routes.ts, server/literature-springer-routes.ts). Those are journal-article indexes. They return papers about NCANDS / ACE / foster-youth CPS — not the underlying tables. For the concept paper's specific statistics, that's exactly the tangential-matches problem you're naming.
RPLICE has no primary-source loader for any of the three. I grep'd the codebase: no ncands-loader, no afcars-loader, no cdc-ace-module-loader. The closest things are server/state-loaders/foster-policy-levers-loader.ts (which encodes the six federal foster-care policy levers as statute facts — Fostering Connections Act, FFPSA, FYI, Chafee/ETV, Medicaid-to-26, FYI centralized application — explicitly NOT the per-state AFCARS rates), and server/cdc-places-loader.ts (CDC PLACES place-based estimates — not the BRFSS ACE module). So the substance of "RPLICE isn't a substitute for the primary-source pull here" is correct.
Wrong detail

The "20 results per query" claim is not accurate as a platform limit. Actual caps in code:
PubMed: default retmax=50, server-clamped to 200 (server/state-loaders/pubmed-loader.ts:96, server/literature-routes.ts:94)
OpenAlex: default perPage=25, capped at 200 (server/state-loaders/openalex-loader.ts:197)
Springer: perPage capped at 100 (server/literature-springer-routes.ts:71)
Crossref: similar pattern
If a caller is seeing 20 results, that's a client-side default in whatever surface they're using, not a platform cap. Worth knowing for the concept paper write-up so the limitation isn't misstated.
Implication for the concept paper

For NCANDS 2022 fatality counts → pull from the Children's Bureau Child Maltreatment 2022 report (HHS/ACF) directly; PDF + supplementary data tables. No RPLICE shortcut.
For CDC ACE percentages → pull from BRFSS ACE Module (state-by-state varies by year of module fielding) via CDC BRFSS or CDC WONDER. No RPLICE shortcut.
For foster-youth CPS rates → AFCARS Foster Care File via NDACAN (DUA-required for restricted files; public AFCARS reports are free). No RPLICE shortcut.
