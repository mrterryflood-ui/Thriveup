## ❓ FREQUENTLY ASKED QUESTIONS

**Q: Do I need to teach Module 1.1 first?**
A: Recommended but not required. Module 1.1 introduces "What is AI?" This module (1.2) teaches how to communicate with AI. Brief review of 1.1 concepts is helpful.

**Q: Can I use this with younger students (K-2)?**
A: Yes, with modifications! Simplify vocabulary, use more visuals, provide more scaffolding. Focus on 2-3 W's instead of all 5. Oral responses instead of written.

**Q: Can I use this with older students (6-12)?**
A: Yes! The concepts apply at all levels. For older students, accelerate pace, use more complex examples, discuss prompt engineering as career, explore advanced applications.

**Q: Do students need AI access to practice?**
A: No! This module teaches the SKILL of creating good prompts. Students don't need to actually use AI during lessons. They're practicing the communication framework.

**Q: What if I don't have devices?**
A: No problem! All activities have paper-based versions. Interactive tools are optional enhancements, not requirements. The workbook is complete on its own.

**Q: How long does this module take?**
A: Standard: 2 weeks, 4 lessons at 20 minutes each. Flexible: Can extend to 25-30 min lessons, or condense to 3 lessons if needed. Assessment adds 25-30 minutes.

**Q: Is this aligned to standards?**
A: Yes! CSTA (computer science), ISTE (technology), CCSS ELA (language arts), and CASEL (social-emotional learning). See teacher guide for details.

**Q: Can I modify the materials?**
A: Absolutely! Files are provided for you to customize. Edit examples, change locations, adjust difficulty. Make it work for YOUR students.

**Q: Do you have Spanish versions?**
A: Not yet, but files are editable! You can translate or work with bilingual staff. Future versions will include Spanish. For now, key vocabulary can be taught bilingually.

**Q: How do I get support?**
A: See "Support & Resources" section below!

## 🆘 TROUBLESHOOTING

### Files Won't Open:

**Workbook/Interactive Tools (HTML files):**
- Right-click file → "Open with" → Select browser (Chrome, Firefox, Safari)
- Or drag file into open browser window
- Or double-click (should open in default browser)

**Teacher Guide (MD file):**
- Open in any text editor (Notepad, TextEdit, VS Code)
- Or use online viewer: dillinger.io
- Or convert to PDF first

### Printing Issues:

**Workbook prints oddly:**
- In print dialog: Check "Print backgrounds" is ON
- Select "Color" not "Black & White"
- Paper size: "Letter" (8.5 x 11 inches)
- Margins: Default
- Try different browser if issues persist

**Text is too small/large:**
- Before printing: Browser zoom to 100% (Ctrl+0 / Cmd+0)
- In print dialog: Scale 100%

### Interactive Tools Not Working:

**Tools don't load:**
- Make sure JavaScript is enabled (check browser settings)
- Try different browser
- Clear browser cache
- Check file isn't corrupted (re-download)

**Progress not saving:**
- Enable cookies/localStorage in browser
- Don't use incognito/private mode
- Some school networks block localStorage (use local file version)

**Drag-and-drop not working:**
- Make sure using mouse/trackpad (touch can be finicky)
- Try different browser
- Keyboard alternative: Click card, then click destination

### Content Issues:

**Examples don't fit my students:**
- Edit HTML files! Change "Austin" to your city
- Modify examples to be culturally relevant
- Adjust reading level if needed

**Need more practice:**
- Repeat activities
- Use extension activities in teacher guide
- Create your own examples following patterns
