### ARCHITECTURAL CORE: THE DYNAMIC RUNTIME STUDIO

Build a built-in Administrative Suite (`/admin/studio`) that turns this application into its own self-hosted IDE and feature publisher:

#### 1. Dynamic Schema-Driven Module Registry (`/src/core/registry`)
* Define a type-safe `GrantModuleManifest` interface that declares:
  - Route path & Navigation grouping.
  - Lifecycle Stage hook (Stages 01–13: Discovery, Qualification, Solicitation Extraction, Adversarial Synthesis, Post-Award Ledger, 27-Category Vault).
  - Form & View UI Schemas (declarative JSON schema that auto-renders dynamic forms, tables, and workflows).
  - Agent Action Hooks (Prompt templates, required data provenance parameters, and scoring rubrics).
* Store registered modules in PostgreSQL (`system_modules` table) with fallback to local JSON files so tools can be hot-loaded at runtime without redeploying code.

#### 2. Embedded Admin Studio (`/admin/studio`)
* **Live Tool Creator / Visual Schema Builder:** Super Admin can create a new grant tool by defining inputs, LLM prompt templates, and output UI formats.
* **Dual-Pane Interactive Sandbox:** Left pane contains raw JSON/TypeScript configuration; Right pane renders the live React component and agent simulation.
* **"Hit Publish" Engine:** Validates the schema, runs security/type checks, stores the new tool in the database registry, and hot-updates the navigation bar in real time for all authorized users.

#### 3. Iron Rules & Verification Pipeline (`/src/core/guardrails`)
Every dynamically registered AI skill must pass through an enforcement middleware:
* **Verbatim Solicitation Parser:** Forces the extraction of `SHALL`, `MUST`, and `REQUIRED` constraints into a verifiable matrix.
* **Evidence Provenance Linker:** Injects mandatory citations (Census, ACS, SAM.gov, 990 data). Replaces missing data with explicit `[EVIDENCE REQUIRED: <gap_description>]` tags.
* **Adversarial Evaluator Standard:** Built-in scoring simulator that compares output to the funder's rubric and produces line-by-line diff corrections.
