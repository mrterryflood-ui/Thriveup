## B. Form B Excel budget — the highest-risk piece (45–60 minutes)

The Form B workbook has hard-coded formulas. Touching them disqualifies the application. Follow this exactly.

1. **Make a working copy.** Right-click `32026-00162_Form_B_Budget_Workbook_1774465344261.xlsx` → Duplicate. Rename the copy `TCAF_FormB_Budget_2026-04-21.xlsx`. Work only in the copy.
2. **Do NOT enable editing in protected cells.** If Excel asks for the "unprotect" password — close it. You should never need it.
3. **Type only in cells colored green or yellow** (input cells). White and grey cells contain formulas. Don't paste, don't drag-fill, don't delete rows.

## F. Submission — Bonfire portal (30 minutes)

1. **Go to** https://twc-texas-gov.bonfirehub.com/opportunities/224162
2. **Sign in.** If you haven't created an account: click "Register" (top right), use mr.terryflood@gmail.com, verify the email, then return to the opportunity page.
3. **Click "Prepare Submission"** (large blue button on the opportunity page).
4. **Read the "Requested Information" panel.** Bonfire lists every required upload slot. The slots typically map to:
   - Form A (Core Application)
   - Form B (Budget Workbook)
   - Form C (T&C Exceptions)
   - Partner Letters of Support
   - 501(c)(3) Determination Letter
   - SAM.gov Registration Confirmation
   - Narrative (if requested separately from Form A)
5. **Upload each file** to its correct slot. Bonfire will reject the wrong format (e.g., uploading .docx where .pdf is required). If a slot says "PDF only," convert first.
6. **Form B uploads as .xlsx.** Do not convert it to PDF — TWC needs the live workbook to verify formulas.
7. **Fill any required text fields** Bonfire shows in the Submission form (often: project title, total request, contact email).
8. **Click "Review."** Bonfire shows a checklist with green checks. Every required item must be green. If anything is red or missing, fix it before continuing.
9. **Click "Submit."** Bonfire will pop up a confirmation. Click "Confirm Submission."
10. **Download the submission receipt.** Bonfire generates a PDF receipt with a confirmation number. Save it as `TCAF_TWC_32026-00162_Receipt_2026-04-21.pdf` in `docs/grants/submitted/`.
11. **Forward the email confirmation** to yourself and to a backup address.
