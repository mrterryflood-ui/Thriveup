**Root cause:** `client/src/components/org-redirect-guard.tsx` was bouncing every signed-in user without an `organization` row to `/onboarding/org` from every route except a tiny `SAFE_PREFIXES` allowlist (which excluded `/`, `/dashboard`, and most workspace surfaces). **Lesson — P-L*N* (cascade-failure guards):** A global redirect guard with an allowlist is a CASCADE-FAILURE pattern — silently breaks every new route the team adds. Inverted block-lists are safer for "only-on-these-routes" semantics. Audit other global guards for the same anti-pattern.

## Eric "Get Funded loops" — SYSTEMATIC fix (live test verified)

**Root cause (revealed by live Playwright test, not breadcrumb inspection):**
- `client/src/lib/queryClient.ts` did `window.location.assign("/onboarding/org")` on ANY 404+ORG_REQUIRED response → full page reload every time any /api/me/* endpoint returned ORG_REQUIRED for a signed-in-no-org user.
- `client/src/pages/grant-hub.tsx:412` queried `/api/me/grants/tracked` (requireOrg) without auth/org gating → /grants (public Live Grant Opportunities) silently hard-redirected to onboarding.
- Combined: every Get Funded click that touched any org-scoped query caused a white-flash reload to /onboarding/org. Eric experienced this as "looping."

**Fix:**
1. Removed the hard `window.location.assign` from `queryClient.ts`. ORG_REQUIRED is now a normal throw — the calling component shows empty/error state. Routes that genuinely need an org are still soft-redirected by `OrgRedirectGuard` (wouter, no reload).
2. `grant-hub.tsx`: `/api/me/grants/tracked` now has `enabled: isAuthenticated`. Added `useAuth` import.

**Verification:** Two live `runTest({testReplitAuth: true})` runs. Post-fix: `/grants` renders for no-org users, `/my-grants` + `/grant-narrative` soft-redirect cleanly, no infinite loops, no "Maximum update depth exceeded."

**Architect (evaluate_task):** Pass. Audited all `/api/me/*` callers — all are either behind `OrgRedirectGuard`-protected routes (`my-grants`, `org-documents-library`, `org-onboarding`, `org-settings`, `rfp-fidelity-*`, `rfp-writer`, `won-proposals`) or already explicitly gated (`partners-join`). Org-present users unaffected.

**Lesson (P-L12):** When a user reports "looping," run the live Playwright test FIRST. Don't iterate route lists or invert match logic.
