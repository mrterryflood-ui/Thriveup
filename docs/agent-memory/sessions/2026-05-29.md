### Key architectural notes
- `profileId = new URLSearchParams(window.location.search).get("pid") || "demo"` — no wouter needed for query params
- `isPersonal = profileId !== "demo"` controls UI differentiation throughout
- Server `create-personal` generates userId=`personal-${Date.now()}-${random}`, inserts participantProfile + residentRiskSnapshot in one transaction
- Server `chainweb-plan` uses `generateAIResponse` (same pattern as justice data-story endpoint)
