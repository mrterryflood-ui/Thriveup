## Connecticut equity-loss geography alignment

- **Decision:** County-equivalent geography changes require an authoritative
  FIPS/crosswalk resolver at every source-access path. Connecticut's
  legacy-source tracts resolve through the Census
  legacy-county/town → Planning Region → 2022 tract → 2010 USALEEP tract
  chain; a display-name match is not valid evidence.
- **Safety boundary:** A source tract that maps to more than one current
  Planning Region is excluded. No copying, averaging, or allocation is
  permitted without a source-supported rule. An unavailable crosswalk or
  unproven Planning Region remains source-unavailable.
- **Coverage semantics:** Analytical coverage is not deployment coverage.
  Reporting must separately describe states, D.C., territories, and record
  availability (present, usable, source-unavailable, otherwise
  suppressed/incomplete, and missing/unattempted). A jurisdiction is wholly
  source-unavailable only when every expected record is present and has that
  reason.
- **Observed development evidence:** The completed batch tested here has
  3,233 present county-equivalent records, 2,721 usable records, no failed
  county computations, and all nine Connecticut Planning Regions resolve
  without statewide source-coverage loss. The live resolver examined 783
  Connecticut source tracts, uniquely resolved 775, and excluded eight
  boundary-spanning tracts; no malformed identifier appeared in the live
  source.
- **Verification:** Zero-error TypeScript; 35 access-model checks; five
  focused alignment/coverage tests; nine nationwide checks; 58 API checks;

  approved independent architect review. A platform-wide completion run had
