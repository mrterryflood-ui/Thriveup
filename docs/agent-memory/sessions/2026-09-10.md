# Session — 2026-09-10

## Task

Catch a stale published Partner API before ChildCORE sees missing scopes.

## Decisions

- The publication check is credential-free by design. It compares the public
  docs response and uses authorization-boundary probes rather than attempting
  to authenticate or write partner data.
- A protected route is considered present only when an unauthenticated request
  reaches `401` or `403`; `404` is reported as deployment drift.
- The bodyless heartbeat probe uses `POST` with no body so it verifies routing
  without creating a partner heartbeat.

## Proof plan

- Run the new script against the local development server and separately
  against the published URL when provided.
- Run TypeScript validation, the relevant heartbeat/security checks, and the
  required preflight and memory-health gates.

  entries, and every protected Chainweb, YHSI, student aggregate, and bodyless
  heartbeat probe.
- The first published check failed closed because production still omitted the
  Chainweb/YHSI docs entries even though its protected routes were present.

  `PUBLISHED_BASE_URL=https://easyailearning.com` check then passed: public docs
