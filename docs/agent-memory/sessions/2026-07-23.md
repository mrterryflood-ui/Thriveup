### Decisions
- HerHealth is NOT a maternal health platform only — it's a comprehensive female health equity/advocacy/education platform spanning urban and rural; domain set must reflect that.
- Bidirectional API uses `partnerReferrals` table keyed by anonymous participant ID only. No PII.
- `requireFeminineNetwork` guard at middleware layer; `resolveFeminineNetworkPlatform` enforces platform.id membership at handler level (double gate).
- All cross-platform events audit-logged to `networkMemberEvents` with full payload for both sender and receiver.
