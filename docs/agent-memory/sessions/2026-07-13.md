## Community Analysis Platform + RPLICE Intervention Overlay (new)

### What was built
- `server/community-intelligence-routes.ts`: Added `POST /api/community-intelligence/interventions` endpoint:
  - Accepts `{ zip, targetZip? }` — both 5-digit US ZIPs
  - Fetches SVI/Census via `fetchZctaData` for source AND target ZIP in parallel
  - `matchProgramsToSVI(svi)`: maps SDOH thresholds to `EVIDENCE_PROGRAMS` domains → returns top 6 matched programs
  - `buildCFIRAdaptation(program, sourceSVI, targetSVI)`: generates 4–5 CFIR 2.0 construct analyses (Inner Setting, Outer Setting, Innovation Characteristics, Individuals, Cross-City Delta)
  - AI narrative via `generateAIJSON` + `withEthicalPreamble`: `{ summary, adaptationSteps[], fidelityWarnings[], fundingBridge }` only if targetZip supplied
  - Returns: sourceProfile, targetProfile, matchedPrograms (with projectedImpact + cfirAdaptation), adaptationNarrative
  - Route registered at top of `registerCommunityIntelligenceRoutes` (not inside request handler — corrected)

- `client/src/pages/community-analysis.tsx`: Major additions:
  - Imports: `useEffect`, `useLocation` from wouter, `Separator`, new lucide icons

  - Full intervention overlay UI section (after 3D section, inside result block):
    - Header with "Run Intervention Analysis" button + optional target ZIP input
