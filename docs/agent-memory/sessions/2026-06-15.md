### Design decisions
- Quick Exit button (→ weather.com) on every survivor-facing page — DV site best practice
- All survivor tools require NO login — maximum accessibility
- Partner portal requires auth — listings/vouchers are partner-attributed
- In-memory store (no DB push needed) — fast to build, persistent during session, migratable to schema later
- Service logs are anonymous (no names, just service type + county + language) — no PII risk
- Impact dashboard is public — this is the OVW eligibility documentation building in real time
- Every service logged counts toward TCAF's "documented history of effective work" (34 U.S.C. § 12291(a)(50))
