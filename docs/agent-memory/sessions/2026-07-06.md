### Key decisions
- Clinical routes mounted WITHOUT requireAuth (self/facilitator-administered; auth is UI-level)
- FOIA routes mounted WITH requireAuth at routes.ts mount level (internal staff tool)
- Employer /register is public; /registrations and /registrations/:id/review use local ensureAuth() inside router
- CareerOneStop sync runs at startup + would need setInterval for daily (not added yet — no creds configured)
- employerPartners.industry is notNull() — employer-registration.ts always passes `industry ?? "General"`
- BJS ingestion silently no-ops if URLs return errors (not a hard failure)
