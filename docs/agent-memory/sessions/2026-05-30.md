**Fix**: Added `openrouter-claude` as a new provider step — uses OpenRouter to call `anthropic/claude-3.5-haiku`. Inserted it immediately after direct Claude in the fallback chain.

**Lesson**: The user correctly noted "OpenRouter should handle this." It was in the chain but only for DeepSeek, not for Claude. OpenRouter supports any Anthropic model via `anthropic/claude-3.5-haiku` model string. Always add the primary-provider-via-OpenRouter step immediately after the direct provider attempt.
