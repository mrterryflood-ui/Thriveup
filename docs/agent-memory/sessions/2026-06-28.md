
## Agency Intelligence Profile (AIP) System — Session 2026-06-28

### What was built
28-agency static profile system wired into the full grant-writing pipeline.

**New file:** `server/agency-profiles.ts` (~1100 lines)
- 28 federal agencies: SAMHSA, HRSA, ACF, DOL/ETA, NSF, OJJDP, HUD, EDA/CEDS, VA, OVW, AmeriCorps, EPA, USDA/FNS, SBA, NEA, IMLS, ORR, FEMA, CDMRP, CMS/CMMI, BJA, NIH D&I, USDA/RD, ACL, DOE Education, CDFI Fund, DOL/VETS, NEH
- Each profile: requiredForms (with live URLs), performanceSystem, languageDictionary, evidenceRequirements, budgetRules, evaluationSignals, ragEntries
- Helpers: `detectProfileFromGrant({agency, cfda, title})`, `getProfileById(id)`, `getAllRagEntries()`

**Extended:** `server/agency-intelligence.ts`
- `getAgencyIntel()` now merges static profile into returned AgencyIntel object
- Monthly resource-page refresh (30-day cadence, AI extracts form/guidance changes)
- `scheduleMonthlyResourceRefresh()` — non-blocking startup job, 10s boot delay, 2s stagger/agency
- USASpending data stays 7-day refresh; resource pages refresh monthly independently

**Extended:** `server/rag-engine.ts`
- `seedKnowledgeBase()` now seeds 34 agency intelligence RAG chunks (category: "federal-agency-intelligence")
- Startup log confirms: "Seeded 88 platform chunks + 34 agency intelligence chunks"

**Extended:** `server/rfp-rubric.ts`
- `buildAgencyIntelBlock()` now renders: required forms checklist + URLs, conditional forms, performance system, language dictionary, evidence requirements, budget rules, reviewer scoring criteria, win factors, common disqualifiers, live resource-page updates

**New endpoint:** `GET /api/agency-profiles/detect`
- Params: `grantId` OR `agency`/`cfda`/`title`
- Returns full structured profile for zero-click intelligence surfacing
- Auth required

### Critical accuracy facts encoded in profiles
- AmeriCorps: apply via eGrants.gov (egrants.cns.gov) NOT Grants.gov
- CDFI Fund: apply via myCDFIfund.gov NOT Grants.gov
- HRSA: must upload in Electronic Handbooks (EHBs at grants.hrsa.gov) IN ADDITION TO Grants.gov
- SAMHSA: SAMHSA budget template is MANDATORY beyond SF-424A
- CDMRP: pre-application gate required; eBRAP (ebrap.org) parallel submission required
- AmeriCorps admin costs capped at 5% of total grant
