**Key normalizer** added to `grantpathpro-routes.ts`: `normalizeKey()` strips leading/trailing whitespace + non-ASCII chars (U+0080–FFFF) from both `provided` and `expected` before comparison. Needed because `THRIVEUP_INBOUND_KEY` env var has a trailing em-dash (—, U+2014) that was copy-pasted into the secret — this prevents HTTP-header-level mangling from breaking auth when GPP sends a clean ASCII key.
