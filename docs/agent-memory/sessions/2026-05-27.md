### Gotcha to deposit to topics/gotchas.md next turn:

When extracting primary sources from attached_assets, `cat` output is often truncated in the assistant's view (long files clipped mid-content). For RFP work where credential/name/dollar/date precision is non-negotiable, always **re-read the file via the `read` tool with explicit limit large enough to capture the signature block**, especially for letters where signatory identity is at the end of the file. This is the verification failure mode that produced the E.1.c placeholder.
