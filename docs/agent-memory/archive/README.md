# Archive (Cold Storage)

Entries that are no longer active working memory but worth preserving for traceability.

## Files

- **`A-series.md`** — chronological numbered milestones (A1, A2, … A27, A27-UPDATE, …). Cross-referenced from `replit.md`, topic files, and session logs as `→ A<n>`. The historical source of truth.
  - For now this lives at the root: **`docs/memory-archive.md`** (unchanged path — many files reference it). The path will not move; this README simply points to it.
- **`resolved-gotchas.md`** — gotchas that no longer apply. Format: `## <gotcha title>` followed by `resolved YYYY-MM-DD: <reason>` and the original text below.

## Rules

- **Append-only.** Never edit a past A-entry; instead add an `A<n>-UPDATE` entry that corrects it (see A27 + A27-UPDATE).
- **Reference, don't duplicate.** Topic files cite `→ A<n>` rather than copying content.
- **No promotion out of archive.** Once cold, stays cold. If an archived gotcha is suddenly hot again, add a fresh entry under `topics/gotchas.md` and reference the archive.
